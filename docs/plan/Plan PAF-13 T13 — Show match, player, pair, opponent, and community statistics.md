**Counting and definitions**

- Counting unit is Game Group, not Match Event. confirmed_groups/played_groups includes confirmed Incomplete; resolved_matches = wins+losses+draws; incomplete_groups separate. UI explains difference. Competitive/Friendly played totals partition confirmed_groups. W/L/D and win percentages exclude Incomplete. Average games per played group uses confirmed_groups (including recorded Incomplete games); label denominator. No outcome from partial game lead.
- Complete normal set awards games exactly once and set win/loss only to greater-score team. Incomplete normal set awards recorded games, zero sets. Third normal set counts games; individual tiebreak points are never added as games. Existing ResultSetRow has games/completed only: use valid V1 normal-game facts; do not infer point counts. Draw with 2–1 incomplete third remains draw. Confirmed Incomplete may retain completed earlier sets/games, zero W/L/D/rating/League effects.
- Win% = wins/(wins+losses+draws); set% and game% use corresponding won+lost. Zero denominator returns null with typed insufficient reason, never 0%, NaN or Infinity. Valid zero counts display 0.
- Straight sets: decisive 2–0 completed-set result, no incomplete set. Three-set count: recorded third normal set, including unfinished third (separate incomplete-decider count). Deciding-set W/L: decisive completed third after first two split. First-set conversion/comeback rates: W/L/D resolved groups with completed decisive first set; numerator actual match wins. Incomplete groups excluded from outcome-rate denominators.
- Form: last up-to-5 and up-to-10 resolved matches, report sample size, not invented missing outcomes. Draw breaks win/loss streak; Incomplete is omitted from resolved sequence and shown separately. Current/best pair streak uses same rule; pending/disputed/canceled never enter sequence.
- Cleanest win: maximum total normal-game differential among wins. Closest win: smallest absolute normal-game differential among wins (not largest set margin). Ties sort by played_at then lowercase group UUID; equal sporting leaders may be shown as ties. Most-frequent partner/opponent ties retain tied identities and deterministic UUID display order.
- Biggest single-match gain/loss: signed applied ledger delta, only applicable Competitive calculations. Upset win: winner had lowest expected win probability; toughest loss: highest expected win probability among losses. Configured upset badge threshold default expected_score <=0.35; calculate neither from current levels nor score margin. Pair opponent-level average uses stored pre-match opposing team strength, excludes groups with missing rating evidence and reports evidence sample size.
- Most active week/month and series: UTC ISO week starting Monday / calendar month. Average matches/week: confirmed_groups divided by max(1, elapsed selected calendar days/7); all-time interval first through last played UTC day inclusive. Explain window; emit zero buckets inside selected observed range. Active players: distinct actual confirmed participants in selected window, not member count. Combinations: canonical actual quartet irrespective of team ordering; common matchup: canonical pair-v-pair identity. Closest rivalry: smallest absolute W-L imbalance among qualifying opposed relationships, then largest sample; show definition.
- Current global level/reliability/starting/highest from rating authority. Lowest established level considers only states with reliability >=100; null until established. Filtered delta sums scoped current committed ledger deltas, not end minus start global level when other communities contribute. Period chart must label scope honestly; current global level never becomes a fabricated community-specific rating.
- Community skill rank: global current level among eligible community members; reuse established tie conventions, never League win order. Active/best League position: shared League sporting rank helpers and snapshots, never rating delta. Historical best skill/League rank requires deterministic materialization at authoritative rating/membership/eligible-result transitions. Reconstruct from available initializations, ledger revisions, membership intervals, eligible results and immutable standings versions; record reconstructed provenance, never manufacture a published historical position. Rank-history coverage boundary must be explicit if original facts are genuinely unavailable; escalate missing required historical proof rather than silently declaring whole metric optional.
- Community leaders include total groups, type split, eligible active-League groups, activity/wins/win%/set/game leaders, scoped improvement, frequent pair/matchup, rivalry, active-player count and weekly/monthly frequency. Count each group once at community level, not four player contributions or two pairs.
- No actual left/right capture found in ResultTeams/ResultSetRow. preferred_side is not actual court side. Hide optional actual-side metrics unless real captured evidence is discovered; no new collection workflow required. Exclude PRD §76 Phase 1.1 enhancements.
