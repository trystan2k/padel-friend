Design system

Mobile-first, WCAG AA in both themes, built for sunlight. One typeface, one action colour, one highlight. Every token below maps 1:1 to a CSS variable in the prototype. Open the prototype →

Principles

One primary actionEach screen has a single green, sticky bottom button. Everything else is secondary or a list row.
Never colour aloneStatus always pairs a glyph and words: ✓ You're in, ◷ Pending, # Reserve, ★ Ranked, W/L/D letters.
48px or biggerButtons 48–52px, list rows 56–72px, chips 44px. Steppers 44px with 6px gaps.
Quiet motion150ms fades for sheets and toasts only. Turned off entirely under prefers-reduced-motion.

Colour

Ratios are text-on-surface (or text on the swatch where noted). Borders on inputs meet the 3:1 non-text minimum.
