## Actual token contrast calculations

WCAG relative sRGB luminance, `(Llighter + 0.05) / (Ldarker + 0.05)`. Unrounded ratio is asserted. All normal text is tested at ≥4.5:1, without relying on large-text exceptions; focus/control boundaries/chart trend ≥3:1. Generated token CSS is read directly by tests so changed palette values invalidate proof. Disabled opacity and composited/overlapping rendered states are not certified by this matrix.

| Actual foreground / background | Light |  Dark |           Threshold |
| ------------------------------ | ----: | ----: | ------------------: |
| text / surface                 | 16.05 | 14.71 |                 4.5 |
| muted / surface-2              |  4.81 |  6.34 |                 4.5 |
| green / surface                |  6.02 |  9.43 | 4.5 text; 3 graphic |
| line / surface-2               |  3.62 |  3.36 |                   3 |
| hero-copy / green-deep         |  9.28 |  9.28 |                 4.5 |

Matrix also covers text/muted/green/red/amber over bg, surface, surface-2 and green-soft; primary bg/surface text on green; hero on-hero/copy/muted/label on green-deep; bg text on red. A passing matrix is not proof that every rendered control uses the intended combination.
